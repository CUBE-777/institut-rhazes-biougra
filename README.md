# موقع معهد الرازي لتكوين الممرضين والممرضات - فرع بيوكرى

## 📁 محتويات المشروع
```
index.html              -> الصفحة الرئيسية (كل شيء في ملف واحد: HTML+CSS+JS)
netlify.toml             -> إعدادات Netlify
admin/
  index.html             -> صفحة تسجيل الدخول للوحة التحكم (Decap CMS)
  config.yml             -> إعدادات لوحة التحكم (الحقول القابلة للتعديل)
content/data/
  settings.json          -> الهاتف، البريد، العنوان، ساعات العمل، روابط التواصل
  announcements.json     -> الإعلانات والأخبار (تظهر أيضاً في الشريط العلوي إن كانت "عاجلة")
  formations.json        -> الشعب والتخصصات
assets/uploads/          -> مجلد الصور التي سترفعها من لوحة التحكم
```

## 🚀 خطوات النشر (GitHub + Netlify + لوحة تحكم Decap CMS)

### 1) رفع المشروع إلى GitHub
- أنشئ مستودعاً (Repository) جديداً على GitHub.
- ارفع جميع ملفات هذا المجلد إليه (على أن يكون الفرع الرئيسي باسم `main`، وهو ما تمت الإشارة إليه في `admin/config.yml`).

### 2) ربط المستودع بـ Netlify
- من لوحة Netlify: **Add new site > Import an existing project**، واختر المستودع.
- إعدادات البناء: اتركها كما هي (لا يوجد أمر بناء Build command، ومجلد النشر Publish directory هو الجذر `.`) — تم ضبط هذا مسبقاً في `netlify.toml`.

### 3) تفعيل Netlify Identity و Git Gateway (لتشتغل لوحة الأدمن)
داخل موقعك على Netlify:
- **Site configuration > Identity > Enable Identity**
- **Identity > Registration preferences**: اختر "Invite only" (بدعوة فقط) حتى لا يسجل أي شخص حساباً عشوائياً.
- **Identity > Services > Git Gateway**: فعّلها (Enable Git Gateway) — هذا ما يسمح للوحة التحكم بالكتابة في GitHub نيابة عنك دون الحاجة لأي مفتاح API يدوي.
- ثم من تبويب **Identity**، اضغط **Invite users** وأدخل بريدك الإلكتروني لإنشاء أول حساب أدمن.

### 4) الدخول إلى لوحة التحكم
بعد قبول الدعوة عبر البريد الإلكتروني وتعيين كلمة مرور، يمكنك الدخول من:
```
https://اسم-موقعك.netlify.app/admin/
```

### 5) استقبال طلبات التسجيل (Netlify Forms)
النموذج (`pre-inscription`) يعمل تلقائياً بمجرد نشر الموقع على Netlify (بفضل خاصية `data-netlify="true"`). لرؤية الطلبات الواردة:
- من لوحة Netlify: **Forms** في القائمة الجانبية لموقعك، ستجد كل طلبات التسجيل مع إمكانية تصديرها أو ربطها بإشعارات بريد إلكتروني (**Forms > Settings > Form notifications**).

## ✏️ ماذا يمكن تعديله من لوحة الأدمن؟
1. **الإعدادات العامة**: الهاتف، البريد الإلكتروني، العنوان (باللغات الثلاث)، أوقات العمل، روابط فيسبوك/انستغرام/يوتيوب، ورابط خريطة Google Maps.
2. **الإعلانات والأخبار**: إضافة/حذف/تعديل أي عدد من الأخبار، مع تفعيل خانة "عاجل" لإظهار أي خبر في الشريط العلوي المتحرك تلقائياً.
3. **الشعب والتخصصات**: تعديل الاسم/الوصف/شرط الولوج/المدة لكل شعبة بثلاث لغات، أو إضافة شعبة جديدة بالكامل.

كل حقل نصي مكرر 3 مرات (عربي/فرنسي/ألماني) حتى تملأه بنفسك بثلاث اللغات دفعة واحدة من نفس الشاشة.

## 🖼️ الصور
- أماكن الصور الرئيسية (الـ Hero وغيرها) تحتوي حالياً على رسوم توضيحية (SVG) مؤقتة بألوان الهوية البصرية، مع تعليق واضح في الكود يشير لموضعها.
- لاستبدالها: يمكنك ببساطة تعديل ملف `index.html` لاحقاً ووضع وسم `<img>` بدل الرسم التوضيحي، أو -بشكل أفضل- إضافتها كخانة صورة عبر `settings.json` وربطها ديناميكياً إن احتجت ذلك مستقبلاً.
- صور الإعلانات (في قسم الأخبار) قابلة للرفع مباشرة من لوحة التحكم لكل خبر.

## 🌍 اللغات
اللغة الافتراضية عند فتح الموقع هي **العربية**، مع إمكانية التبديل الفوري للفرنسية والألمانية عبر الأزرار في الهيدر (وتُحفظ اللغة المختارة تلقائياً للزيارة القادمة عبر `localStorage`).
